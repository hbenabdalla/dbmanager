# DBManager 0.15.3

**DBManager 0.15.3** is a packaging release of milestone 0.15 — **Cloud-Native Deployment**. The
application is unchanged from [0.15.1](0.15.1.md) (no migration; schema `0014`). What changes is
how the Helm chart presents itself on [Artifact Hub](https://artifacthub.io/packages/search?repo=dbmanager).

## Added

- A chart README, shown on Artifact Hub. It covers what DBManager does, what the chart deploys,
  install, production and OpenShift values, the main settings, upgrades, signature verification
  and uninstall.
- Artifact Hub annotations: the category, documentation and source links, and the images the
  chart deploys (Artifact Hub scans these for vulnerabilities).
- Repository metadata for Artifact Hub's Verified Publisher label, published to the chart
  repository's `artifacthub.io` tag.

## About 0.15.2

The `v0.15.2` tag was pushed while the product and chart still said 0.15.1. The release workflow
refused the tag before publishing anything: it requires the tag, the product version and the chart
version to agree. Published tags are not moved, so this release is 0.15.3.

## Upgrade

```bash
helm upgrade dbm oci://ghcr.io/hbenabdalla/charts/dbmanager --version 0.15.3 -n dbmanager --reuse-values
```

Full list of changes: [changelog](https://github.com/hbenabdalla/dbmanager/blob/main/CHANGELOG.md).
