# DBManager 0.15.1

**DBManager 0.15.1** is the first published release of milestone 0.15 — **Cloud-Native
Deployment**. It contains everything in [0.15.0](0.15.0.md): the Helm chart for Kubernetes and
OpenShift, signed images with SBOMs, highly available replicas with a visible scheduler leader,
and TLS to the control-plane databases.

## Why 0.15.1

The `v0.15.0` tag was pushed, but its release workflow stopped before publishing anything: it
referenced `sigstore/cosign-installer@v4`, a tag that action does not have. No images, chart or
GitHub release exist for 0.15.0, and the tag is kept as it is (published tags are not moved).
0.15.1 fixes the workflow and is published in full.

## Fixed

- Release workflow: `sigstore/cosign-installer` pinned to `v4.1.2`; every action reference in the
  workflows was checked to resolve.
- Backend CI: the control-plane TLS test used a certificate that also names `127.0.0.1`, so its
  check that `verify-full` refuses an unnamed address could not pass. CI now generates a
  certificate without IP addresses. `verify-full` itself was correct.
- The Docker test runner now also runs the VictoriaMetrics suite (it was started but its tests
  were deselected).
- Test certificates now have the key identifiers that strict X.509 verification (Python 3.13+)
  requires.

## Upgrade notes

None beyond [0.15.0](0.15.0.md#upgrade-notes). No migration; schema stays `0014`.

```bash
helm install dbm oci://ghcr.io/hbenabdalla/charts/dbmanager --version 0.15.1 -n dbmanager --create-namespace -f my-values.yaml
cosign verify ghcr.io/hbenabdalla/dbmanager-backend:0.15.1 \
  --certificate-identity-regexp 'https://github.com/hbenabdalla/dbmanager/.github/workflows/release.yml@refs/tags/v.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

## Testing

The full real-engine Docker matrix on the 0.15.0 code (2026-10-21): **89 passed, 0 failed,
1 skipped** (Oracle TCPS) — PostgreSQL 16, MySQL 8.4, MariaDB 11.4 (both with TLS verified),
SQL Server 2022, Oracle 21c XE, Db2 LUW 11.5, OpenLDAP, Keycloak and Vault.

On the 0.15.0 code, GitHub Actions passed *Kubernetes* (kind install, `helm test`, leader failover),
*Docker images* (Compose start and restore drill), *Documentation* and *Security*; *Backend*
failed only on the test fixed here, which was reproduced and verified against PostgreSQL 16 with
both certificates.
