# Task guides

Each guide states the goal, what you need before you start (permissions and setup), numbered
steps with the labels you see in the application, what you should see at the end, and where to
look when it does not work.

| Task | Typical role |
|---|---|
| [Register a database](register-a-database.md) | DBA, platform team |
| [Onboard an environment in bulk](bulk-onboard-an-environment.md) | platform team |
| [Investigate a slow query](investigate-a-slow-query.md) | DBA, performance engineer |
| [Respond to an alert](respond-to-an-alert.md) | on-call DBA, operator |
| [Review security findings and compliance](review-security.md) | security auditor, DBA |
| [Back up and restore a database](backup-restore-database.md) | DBA, backup operator |
| [Back up and restore the platform](backup-restore-platform.md) | platform administrator |
| [Schedule a report](schedule-a-report.md) | anyone with reports, platform administrator |
| [Give a colleague scoped access](give-scoped-access.md) | platform administrator |

Permissions are named as in [Roles and permissions](../../administration/rbac.md). If a page or
button described here is missing, your role does not include the permission it needs: the user
menu (top right) lists your roles and their scopes under **Access**.
