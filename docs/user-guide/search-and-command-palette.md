# Search and command palette

Press **Ctrl + K** (Windows/Linux) or **Cmd + K** (macOS), or select the search box in the top bar.

* **Servers** — type part of a name; results show health, engine and environment.
* **Actions** — add a database server, bulk onboarding, open the topology, review security posture,
  configure an identity provider, run the setup wizard, toggle light/dark theme. Only actions your
  role allows are listed.
* **Pages** — every page of the sidebar you can open.

The **+ Add** button in the top bar offers the same creation actions (server, bulk onboarding,
environment, database user, platform user, identity provider), filtered by permission.

Other shortcuts: the theme toggle (sun/moon) in the top bar; **Collapse** at the bottom of the
sidebar switches to an icon rail; sidebar groups remember whether they are collapsed.
