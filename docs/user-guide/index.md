# User guide

This guide follows the sidebar of the application. What you see depends on your role: pages and
actions you have no permission for are hidden, and servers outside your scope do not exist for you.

| Sidebar group | Pages |
|---|---|
| Overview | [Dashboard](dashboard.md), [Topology](topology.md), [Fleet](fleet.md), [Reports](reports.md) |
| Operations | [Monitoring and performance](performance.md), [Sessions and locks](sessions-and-locks.md), [Replication](replication.md), [Queries and plans](queries-and-plans.md), [Databases, schemas and objects](databases-and-objects.md), [Users and privileges](users-and-privileges.md) |
| Optimization | [Recommendations](recommendations.md) |
| Security | [Security](security.md), [Audit](audit.md) |
| Platform | [Setup wizards](onboarding/index.md) and the [administration pages](../administration/index.md) |

Every server has its own page with tabs — see [Servers](servers.md). Use **Ctrl/Cmd + K** to jump
anywhere ([Search and command palette](search-and-command-palette.md)).

## Real and simulated data

When a [simulated fleet](simulation.md) exists, simulated servers carry a *Simulated* badge and a
hatched pattern, and the source filter on fleet pages switches between *Real*, *Simulated* and *All*.
