# Fleet

**Fleet → All servers** lists every server you may see, with engine and version, environment,
health, connection utilization, latency, open advice and last collection. Filter by text, engine,
environment, health or tag; sort any column.

| Page | Purpose |
|---|---|
| All servers | inventory and entry point to each [server](servers.md); **Add server** opens the [onboarding wizard](onboarding/database-onboarding.md) |
| Clusters | primary/replica, RAC, availability-group and HADR groupings with member roles |
| Databases | every database across the fleet with size and owner server |
| Environments | production, DR, UAT, development, test tiers; production gets stricter confirmations |
| Bulk onboarding | register many servers from a grid, CSV or JSON — [Bulk onboarding](onboarding/bulk-onboarding.md) |

Sites, applications and tags are assigned during onboarding or in a server's **Settings** tab and
are used for filtering, topology grouping and RBAC scopes.

Topology view of the same inventory: [Topology](topology.md).
