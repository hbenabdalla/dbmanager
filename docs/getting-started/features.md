# Features

| Area | What you get | Learn more |
|---|---|---|
| Dashboard | command-center KPIs with 24 h trends; fleet map, engines and environments act as filters | [Dashboard](../user-guide/dashboard.md) |
| Fleet | servers, clusters, databases, environments, sites, applications, tags; bulk onboarding | [Fleet](../user-guide/fleet.md) |
| Topology | interactive Environment → Site → Cluster → Server → Database map; replication diagram | [Topology](../user-guide/topology.md) |
| Monitoring | live metric cards, charts from 15 minutes to 90 days, drag-to-zoom, health status | [Performance](../user-guide/performance.md) |
| Queries | top statements per engine, statement history, graphical execution plans, SQL workspace | [Queries and plans](../user-guide/queries-and-plans.md) |
| Sessions and locks | active sessions, blocking chains, cancel/terminate with confirmation | [Sessions and locks](../user-guide/sessions-and-locks.md) |
| Recommendations | performance, query and configuration advice with evidence | [Recommendations](../user-guide/recommendations.md) |
| Security | posture score, findings, privileged accounts, compliance view | [Security](../user-guide/security.md) |
| Administration | guarded, previewed, audited changes per engine | [Users and privileges](../user-guide/users-and-privileges.md) |
| Reports | CSV exports (fleet health, inventory, capacity, performance, slow queries, security, privileged users, recommendations, audit activity) | [Reports](../user-guide/reports.md) |
| Identity | local accounts, LDAP/AD, OIDC (Keycloak, Entra ID, Okta, generic), group mapping | [Identity providers](../administration/identity-providers.md) |
| RBAC | permissions scoped to platform, environment, site, cluster, application, server, database | [RBAC](../administration/rbac.md) |
| Audit | every sign-in, change, denied action and administration statement | [Audit](../user-guide/audit.md) |
| Demo | a clearly labelled, removable simulated fleet | [Demo environment](demo-environment.md) |

What is **not** in the product yet (alert notifications beyond what the alerting pages describe,
scheduled reports, PDF export, SAML, Windows authentication for SQL Server, Db2 for z/OS thread and
lock monitoring, …) is listed in the [gap analysis](../product/gap-analysis.md).
