## Rebuilding the videos

1. Start the application with a simulated fleet (Platform → Simulation) and capture 1920 × 1080
   screenshots of the pages named in the storyboards (`dashboard-overview`, `topology`,
   `server-performance`, `sessions`, `query-performance`, `security-posture`, `recommendations`,
   `backup-dashboard`, `database-onboarding-engine-selection`, `collectors`).
2. Install the tools: `pip install pillow cairosvg fonttools numpy soundfile kokoro-onnx`, `ffmpeg`,
   and the frontend dependencies (`cd frontend && npm ci`, for the Plus Jakarta Sans files).
3. Optional narration: download the Kokoro TTS model files (`kokoro-v1.0.onnx`, `voices-v1.0.bin`,
   Apache-2.0, from the kokoro-onnx releases). Without them the videos are rendered with music only.
4. Run:

   ```bash
   python marketing/video/build_videos.py --footage <screenshots> --out <dir> \
     --tts-model kokoro-v1.0.onnx --tts-voices voices-v1.0.bin
   ```

The music bed is generated by the script (no third-party audio). Narration is synthesised speech;
a recorded voice-over can replace it by reading the narration column of the storyboards.
